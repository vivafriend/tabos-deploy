## 1. 安装必需软件

### 1.1 安装 MySQL

1. 点击左侧菜单 **软件商店**
2. 找到 **MySQL** 
3. 选择版本 **MySQL 8.0** 或 **MySQL 5.7**
4. 点击 **安装**
5. 选择 **极速安装**
6. 等待安装完成

### 1.2 安装 Redis

1. 软件商店搜索 **Redis**
2. 选择 **Redis 7.0** 或更高版本
3. 点击 **安装**
4. 等待安装完成

### 1.3 安装 Nginx

1. 软件商店找到 **Nginx**
2. 选择 **Nginx 1.22** 或更高版本
3. 点击 **安装**
4. 编译安装（推荐）
5. 等待安装完成

### 1.4 验证软件运行状态

在宝塔面板首页查看：
- MySQL：运行中（绿色）
- Redis：运行中（绿色）
- Nginx：运行中（绿色）

## 2. 上传项目文件

### 2.1 创建项目目录

1. 点击左侧 **文件**
2. 进入 `/www/wwwroot/`
3. 点击 **新建目录**，输入 `tabos`
4. 进入 `tabos` 目录
5. 新建两个子目录：`backend` 和 `frontend`

目录结构：
```
/www/wwwroot/tabos/
├── backend/
└── frontend/
```

### 2.2 上传后端文件

**方式一：宝塔文件管理器上传**

1. 进入 `/www/wwwroot/tabos/backend/`
2. 点击 **上传**
3. 选择 `tabos-backend` 可执行文件
4. 等待上传完成
5. 右键文件 → **权限** → 设置为 `755`

**方式二：使用 FTP 上传**

1. 宝塔面板 → **FTP** → 添加 FTP
2. 使用 FileZilla 连接
3. 上传文件到 `/www/wwwroot/tabos/backend/`

### 2.3 上传前端文件

1. 进入 `/www/wwwroot/tabos/frontend/`
2. 点击 **上传**
3. 上传前端 `dist` 目录下的所有文件
4. 或者上传压缩包后解压

前端目录应包含：
```
frontend/
├── index.html
├── assets/
├── favicon.ico
└── ...
```

## 3. 创建网站

### 3.1 添加站点

1. 点击左侧 **网站**
2. 点击 **添加站点**
3. 填写配置：

| 配置项 | 填写内容 |
|--------|---------|
| 域名 | 你的域名，如 `tabos.example.com` |
| 根目录 | `/www/wwwroot/tabos/frontend` |
| FTP | 不创建 |
| 数据库 | 不创建（稍后手动创建）|
| PHP 版本 | 纯静态 |

4. 点击 **提交**

### 3.2 验证网站创建

1. 网站列表中出现你的域名
2. 点击域名 → **设置** → **网站目录**
3. 确认运行目录为 `/www/wwwroot/tabos/frontend`
4. 开启 **防跨站攻击** 关闭

---

## 4. 配置数据库

### 4.1 创建数据库

1. 点击左侧 **数据库**
2. 点击 **添加数据库**
3. 填写信息：

| 配置项 | 填写内容 |
|--------|---------|
| 数据库名 | tabos |
| 用户名 | tabos |
| 密码 | 自动生成或自定义（记录下来）|
| 访问权限 | 本地服务器 |
| 编码 | utf8mb4 |

4. 点击 **提交**
5. **复制保存数据库密码**

### 4.2 查看 MySQL 连接信息

1. 软件商店 → MySQL → **设置**
2. 查看端口（默认 3306）
3. root 密码可在此修改

### 4.3 查看 Redis 连接信息

1. 软件商店 → Redis → **设置**
2. 查看端口（默认 6379）
3. 查看是否设置了密码

---

## 5. 启动后端服务

### 5.1 测试后端启动

1. 点击左侧 **终端**
2. 进入后端目录：
```bash
cd /www/wwwroot/tabos/backend
```

3. 给予执行权限：
```bash
chmod +x tabos-backend
```

4. 测试运行：
```bash
./tabos-backend
```

5. 看到以下信息说明正常：
```
✅ 配置文件加载成功
🚀 服务已启动，监听: 0.0.0.0:18080
```

6. 按 `Ctrl + C` 停止

### 5.2 创建 Supervisor 守护进程

1. 软件商店搜索 **Supervisor**
2. 点击 **安装**
3. 安装完成后点击 **设置**
4. 点击 **添加守护进程**
5. 填写配置：

| 配置项 | 填写内容 |
|--------|---------|
| 名称 | tabos-backend |
| 运行目录 | /www/wwwroot/tabos/backend |
| 启动命令 | /www/wwwroot/tabos/backend/tabos-backend |
| 进程数量 | 1 |

6. 点击 **确定**
7. 点击 **启动**
8. 状态显示 **运行中**

### 5.3 验证后端运行

在终端执行：
```bash
curl http://127.0.0.1:18080/api/v1/health
```

返回：
```json
{"code":0,"message":"ok"}
```

## 7. 配置反向代理

### 7.1 通过宝塔界面配置（推荐）

1. **网站** → 找到你的站点 → **设置**
2. 点击 **反向代理**
3. 点击 **添加反向代理**

**配置 1：添加 /api 代理**

| 配置项 | 填写内容 |
|--------|---------|
| 代理名称 | tabos-api |
| 目标 URL | http://127.0.0.1:18080 |
| 发送域名 | $host |
| 内容替换 | 留空 |

点击 **提交**

4. 点击 **配置文件**，找到刚才添加的代理规则
5. 删除宝塔自动生成的配置
6. 替换为以下完整配置：

```nginx
location ^~ /api/uploads {
    proxy_pass http://127.0.0.1:18080;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_http_version 1.1;
}

location ^~ /api
{
    proxy_pass http://127.0.0.1:18080;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header REMOTE-HOST $remote_addr;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_http_version 1.1;
    
    proxy_buffering off;
    
    client_max_body_size 10m;
    
    proxy_connect_timeout 60s;
    proxy_send_timeout 86400s;
    proxy_read_timeout 86400s;
    
    add_header Cache-Control "no-cache, no-store, must-revalidate";
    add_header Pragma "no-cache";
    add_header Expires "0";
}

location ^~ /install {
    proxy_pass http://127.0.0.1:18080;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_http_version 1.1;
    add_header Cache-Control "no-cache, no-store, must-revalidate";
}

location ~ ^/kuwo-cdn/([^/]+)(/.*)$ {
    resolver 8.8.8.8 valid=300s;
    resolver_timeout 5s;

    set $kuwo_host $1;
    set $kuwo_path $2;

    proxy_pass http://$kuwo_host$kuwo_path$is_args$args;
    proxy_set_header Host $kuwo_host;
    proxy_set_header Referer "https://www.kuwo.cn/";
    proxy_set_header User-Agent "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36";
    proxy_set_header Range $http_range;
    proxy_set_header If-Range $http_if_range;

    proxy_buffering off;

    proxy_connect_timeout 10s;
    proxy_send_timeout 60s;
    proxy_read_timeout 60s;

    proxy_force_ranges on;

    add_header Access-Control-Allow-Origin "*" always;
    add_header Access-Control-Allow-Methods "GET, HEAD, OPTIONS" always;
    add_header Access-Control-Allow-Headers "Range" always;
    add_header Access-Control-Expose-Headers "Content-Range, Content-Length" always;

    if ($request_method = OPTIONS) {
        return 204;
    }
}

location / {
    try_files $uri $uri/ /index.html;
}
```

7. 点击 **保存**

### 7.2 验证反向代理

浏览器访问：
```
https://tabos.example.com/api/v1/health
```

返回：
```json
{"code":0,"message":"ok"}
```

## 8. 配置管理后台

### 8.1 访问管理后台

浏览器访问：
```
https://tabos.example.com/admin/
```

使用安装时创建的管理员账号登录。

### 8.2 绑定站点地址

1. 登录管理后台
2. 左侧菜单 → **系统设置** → **站点设置**
3. 在 **站点地址（URL）** 框中填写：
```
https://tabos.example.com
```
4. 点击 **保存**

### 8.3 验证 WebSocket 连接

1. 访问前端首页：`https://tabos.example.com`
2. 按 `F12` 打开浏览器开发者工具
3. 切换到 **Console** 标签
4. 查看是否有以下成功信息：
```
WebSocket connection established: wss://tabos.example.com/api/v1/ws/realtime
```

如果出现 WebSocket 连接失败，检查管理后台的站点地址是否正确。

## 9. 配置 HTTPS

### 9.1 申请 SSL 证书

1. **网站** → 你的站点 → **设置**
2. 点击 **SSL**
3. 选择 **Let's Encrypt**
4. 勾选你的域名
5. 点击 **申请**
6. 等待证书申请成功

### 9.2 开启强制 HTTPS

1. SSL 页面下方
2. 开启 **强制 HTTPS**
3. 点击 **保存**

### 9.3 验证 HTTPS

浏览器访问：
```
https://tabos.example.com
```

查看地址栏是否显示锁图标。

## 10. 常见问题

### 10.1 后端启动失败

**检查步骤：**

1. Supervisor → tabos-backend → 查看日志
2. 查看错误信息
3. 常见原因：
   - 端口 18080 被占用
   - 数据库连接失败
   - Redis 连接失败

**解决方法：**
```bash
netstat -tuln | grep 18080
```

### 10.2 WebSocket 连接失败

**检查清单：**

1. 管理后台站点地址是否正确填写
2. Nginx 反向代理配置是否正确
3. Supervisor 中后端服务是否运行

### 10.3 上传文件大小限制

1. **网站** → **设置** → **配置文件**
2. 找到 `client_max_body_size`
3. 修改为需要的大小，如 `100m`
4. 保存

### 10.4 前端页面空白

**检查：**

1. 网站目录是否正确
2. index.html 是否存在
3. 浏览器开发者工具 Console 是否有错误

### 10.5 访问 /install 显示 404

**原因：**反向代理配置未生效

**解决：**重新检查第 8 步的反向代理配置
